# Praktikum8
## PENJELASAN PROGRAM 

Program ini dibuat menggunakan konsep class pada Python. Class NilaiMahasiswa digunakan untuk menyimpan dan mengelola daftar nilai mahasiswa.

1. tambah(nama, nilai)

Digunakan untuk menambahkan data mahasiswa ke dalam list data.
Setiap data disimpan dalam bentuk dictionary:

{"nama": nama, "nilai": nilai}


---

2. tampilkan()

Menampilkan seluruh daftar nilai mahasiswa. Jika kosong, akan memberi pesan bahwa belum ada data.


---

3. hapus(nama)

Menghapus data berdasarkan nama. Program mencari nama dalam list dan menghapusnya jika ditemukan.


---

4. ubah(nama, nilai_baru)

Mengubah nilai mahasiswa berdasarkan nama. Jika nama ada, nilai diperbarui.


---

5. Main Program

Menunjukkan contoh penggunaan class:

Menambah data

Menampilkan data

Mengubah data

Menghapus data
